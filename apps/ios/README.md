# 📚 Электронный дневник obr57 (burmalda57) — iOS

Неофициальный клиент электронного дневника Орловской области ([obr57.ru](https://obr57.ru/gis)).
Написан на **Rust + [Slint](https://slint.dev)** (рендер Skia / Metal на iOS).

![platform](https://img.shields.io/badge/platform-iOS%2015%2B-black)
![arch](https://img.shields.io/badge/arch-arm64-blue)
![license](https://img.shields.io/badge/license-Apache--2.0-lightgrey)

> ⚠️ **Неофициальный проект.** Не связан с Департаментом образования Орловской области, порталом Госуслуг/ЕСИА
> или разработчиками официального дневника. Используется на свой страх и риск.
> ⚠️ **БЕТА** — возможны сбои и ошибки.

Сборка выполняется вручную на Mac. На выходе получается **неподписанный `.ipa`**, который подписывается
уже при установке на ваш iPhone/iPad (платный аккаунт Apple Developer не требуется).

## ✨ Возможности

- 📊 Оценки по предметам: четверти/периоды, веса оценок, взвешенный средний балл.
- 🎯 Симулятор среднего балла.
- 📈 Графики успеваемости по каждому предмету.
- 📅 Дневник и расписание: уроки, кабинеты, учителя, темы и домашние задания.
- 📝 Заметки к урокам (шифруются локально).
- 🗓️ Личные события в сетке расписания и календарь для быстрого перехода по дням.
- 👨‍👩‍👧 Кабинет родителя с переключением между детьми.
- 🎮 Демо-режим без авторизации через Госуслуги.
- 🔔 Уведомления о новых оценках (см. [ограничения iOS](#️-ограничения-ios)).

## 🔒 Приватность и безопасность

- **Приложение открытое.** Весь код в этом репозитории — его можно прочитать и собрать самостоятельно.
- **Пароль от Госуслуг приложение не видит и не хранит.** Вход через ЕСИА открывается в системном `WKWebView`
  на официальной странице портала; куки веб-вью не сохраняются (непостоянное хранилище).
- **Хранится только результат входа** — сессионная кука и `apikey`, в зашифрованном виде (AES-256-GCM).
  Ключ-обёртка лежит в **iOS Keychain**.
- **Данные уходят только на официальные серверы** регионального дневника. Сторонних бэкендов нет.
- **Офлайн-работа:** расписание и оценки кешируются в зашифрованном виде. При выходе из аккаунта кеш удаляется.
- **Единственное внешнее исключение — Sentry** (технические отчёты о падениях, без персональных данных).
  Отключить: уберите зависимость `sentry` из `rust/Cargo.toml` и блок `sentry::init(...)` в `rust/src/lib.rs`.
- Рекламы, трекеров и аналитики поведения нет.

## 🛠️ Сборка вручную

Нужны: **macOS**, **Xcode** (с Command Line Tools), **Rust**, `cmake` и `ninja`.

### 1. Подготовка

```bash
rustup target add aarch64-apple-ios
brew install cmake ninja
```

### 2. Компиляция

```bash
cd rust
IPHONEOS_DEPLOYMENT_TARGET=15.0 cargo build --release \
  --target aarch64-apple-ios \
  --bin burmalda57-ios \
  --features ios-app
```

Первая сборка долгая (подтягивается и собирается Skia). Результат —
`rust/target/aarch64-apple-ios/release/burmalda57-ios`.

> Cargo может обновить `Cargo.lock` под iOS-зависимости — это нормально.

### 3. Упаковка в `.ipa`

Из папки `rust/`:

```bash
VERSION=$(grep -m1 '^version' Cargo.toml | cut -d'"' -f2)
APP=build/Payload/burmalda57.app

rm -rf build && mkdir -p "$APP"
cp target/aarch64-apple-ios/release/burmalda57-ios "$APP/burmalda57"
chmod +x "$APP/burmalda57"
sed -e "s/@VERSION@/${VERSION}/" -e "s/@BUILD@/1/" ios/Info.plist > "$APP/Info.plist"
plutil -lint "$APP/Info.plist"
cp ios/icons/*.png "$APP/"
printf 'APPL????' > "$APP/PkgInfo"

(cd build && zip -qry "burmalda57-${VERSION}-unsigned.ipa" Payload)
ls -lh build/*.ipa
```

Готовый файл: `rust/build/burmalda57-<версия>-unsigned.ipa`.

## 📲 Установка на iPhone / iPad

Так как `.ipa` не подписан, его нужно «переподписать» своим Apple ID при установке. Выберите один из способов:

| Способ | Что нужно | Срок действия |
|---|---|---|
| [**AltStore**](https://altstore.io) | бесплатный Apple ID, ПК или Mac | 7 дней; AltStore продлевает автоматически, пока ПК/Mac в одной сети |
| [**Sideloadly**](https://sideloadly.io) | бесплатный Apple ID, ПК или Mac, кабель | 7 дней; нужно переустанавливать вручную |
| [**TrollStore**](https://github.com/opa334/TrollStore) | устройство с поддерживаемой версией iOS | бессрочно |

### Sideloadly (самый простой вариант)

1. Установите Sideloadly на компьютер, подключите iPhone кабелем и подтвердите «Доверять этому компьютеру».
2. Перетащите `.ipa` в окно Sideloadly.
3. Введите свой Apple ID и нажмите **Start**.
4. На телефоне: **Настройки → Основные → VPN и управление устройством** → выберите свой Apple ID → **Доверять**.

### AltStore

1. Установите AltServer на компьютер и поставьте через него AltStore на iPhone.
2. Передайте `.ipa` на телефон (AirDrop / Файлы) и откройте его через **AltStore → My Apps → «+»**.

### TrollStore

Откройте `.ipa` через TrollStore («Поделиться → TrollStore») — приложение установится без ограничения по сроку.

### Режим разработчика (iOS 16+)

Для запуска приложений, установленных вне App Store, включите:
**Настройки → Конфиденциальность и безопасность → Режим разработчика** → включить → перезагрузить устройство → подтвердить.

> Пункт появляется только после того, как на устройство хотя бы раз поставили приложение через Sideloadly/AltStore.

## ⚠️ Ограничения iOS

- **Уведомления о новых оценках приходят не каждые 30 минут.** Без Apple Push (нужен платный аккаунт и сервер)
  остаётся только фоновое обновление `BGAppRefreshTask`; момент запуска выбирает iOS — обычно раз в несколько часов,
  чаще, если приложением часто пользуются. Гарантий нет.
- При переподписи приложения **другим Apple ID** ключ в Keychain становится недоступен: приложение создаст новый
  ключ, и придётся войти заново (кэш подтянется с сервера).
- Экран зафиксирован в **портретной** ориентации.
- Бесплатный Apple ID: подпись действует 7 дней и допускает не более 3 активных приложений, установленных таким способом.

## 🧩 Чем iOS-версия отличается от Android

| Android | iOS |
|---|---|
| Slint + FemtoVG/EGL | Slint + winit + **Skia (Metal)** |
| `cdylib` `.so` + NativeActivity | обычный бинарник `burmalda57-ios` (`src/main.rs`), упаковывается в `.app` |
| `EsiaAuthActivity` (WebView) | `WKWebView` с непостоянным хранилищем куков (`ios/glue.m`) |
| Android Keystore | ключ-обёртка в Keychain, тот же формат файлов (`crypto.rs`) |
| `AvatarPickerActivity` | `PHPickerViewController` |
| WorkManager, каждые ~30 мин | `BGAppRefreshTask` + локальные уведомления |
| Toast | плашка поверх окна |
| Material You | светлая/тёмная тема системы |
| status bar 28 px | реальные safe-area отступы (вырез, Dynamic Island) |

## 🗂️ Структура проекта

```
.
└── rust/
    ├── Cargo.toml              # зависимости (цели android/ios разделены через cfg)
    ├── Cargo.lock
    ├── build.rs                # компиляция Slint-UI и ios/glue.m, линковка фреймворков
    ├── assets/                 # ресурсы UI
    ├── ui/                     # Slint-интерфейс (экраны и компоненты)
    ├── src/
    │   ├── main.rs             # точка входа iOS-бинарника
    │   ├── lib.rs              # общая логика приложения
    │   ├── ios.rs              # Rust-часть мостов к Objective-C
    │   ├── platform.rs         # платформенные вызовы из общего кода
    │   ├── session_flow.rs     # вход и навигация «Назад» (общая для платформ)
    │   └── ...                 # diary, marks, net, crypto, notify, profile и т.д.
    ├── ios/
    │   ├── Info.plist          # манифест приложения (bundle id: ru.burmalda.journal)
    │   ├── glue.m              # WKWebView, Keychain, PHPicker, уведомления, BGTask
    │   └── icons/              # иконки приложения
    └── vendor/                 # вендоренный бэкенд Slint (нужен из-за [patch.crates-io])
```

> 📝 Файл `src/android.rs` и `vendor/i-slint-backend-android-activity/` остаются в проекте намеренно:
> `android.rs` исключается из iOS-сборки через `#[cfg(target_os = "android")]`, а `vendor/` указан в секции
> `[patch.crates-io]` в `Cargo.toml`, и cargo требует, чтобы этот путь существовал.

## ❓ Частые проблемы

| Проблема | Решение |
|---|---|
| Не появляется «Режим разработчика» | Сначала установите любое приложение через Sideloadly/AltStore, затем перезагрузите iPhone. |
| Приложение не запускается через 7 дней | Истёк срок подписи бесплатного Apple ID — переустановите `.ipa` (AltStore делает это сам). |
| «Ненадёжный разработчик» | Настройки → Основные → VPN и управление устройством → Доверять. |
| После переподписи просит войти заново | Ожидаемо при смене Apple ID — см. «Ограничения iOS». |
