# 📚 Электронный дневник obr57 (burmalda57) — Web

Неофициальный **веб-клиент** электронного дневника Орловской области ([obr57.ru](https://obr57.ru/gis)).
Ядро написано на **Rust**, интерфейс — [Slint](https://slint.dev), всё компилируется в **WebAssembly** и работает прямо в браузере, без серверной части.

> ⚠️ **Неофициальный проект.** Не связан с Департаментом образования Орловской области, порталом Госуслуг/ЕСИА или разработчиками официального дневника. Используется на свой страх и риск.

## ✨ Возможности

- 📊 Оценки по предметам: периоды, веса, средние баллы
- 📈 Графики успеваемости
- 📅 Дневник, расписание и домашние задания
- 🎓 Итоговые оценки за периоды
- 🗓️ Свои события
- 👤 Профиль: ФИО, школа, класс
- 🌙 Ночной режим (следует системной теме)

> Раньше проект был Android-приложением (Rust + Kotlin-хелперы); Kotlin-часть
> полностью удалена — теперь это чистый wasm-клиент. Фоновые push-уведомления
> и аватар доступны только в мобильной версии и на вебе отключены.

## 🔒 Приватность и безопасность

- **Пароль от Госуслуг приложение не видит и не хранит.** Логин и пароль ты
  вводишь на настоящей странице госуслуг; приложение использует только
  сессионную куку `X1_SSO`, которую пользователь вставляет в окно входа.
- **Сессия хранится на клиенте шифрованно (envelope encryption, как было с
  Android Keystore):**
  - данные (сессия, кеши дневника, отметки ДЗ) шифруются **AES-256-GCM**;
  - ключ шифрования данных (DEK) генерируется случайно и **заворачивается
    неизвлекаемым ключом KEK** из `window.crypto.subtle` — у KEK стоит
    `extractable = false`, экспортировать его из браузера невозможно;
  - KEK живёт в **IndexedDB**, завёрнутый DEK — в localStorage; сам DEK в
    открытом виде никогда не попадает на диск;
  - HKDF-SHA256 разделяет ключи по назначению (сессия / кеши).
- **Данные уходят только на официальные серверы** дневника
  (`mp2.obr57.ru`). Никаких сторонних бэкендов нет. Телеметрии нет.
- Никакой рекламы, трекеров и аналитики поведения.
- «Выйти» стирает сессию и все серверные кеши из хранилища браузера.

### CORS

Браузер требует разрешения сервера на кросс-доменные запросы. Если
`mp2.obr57.ru` не отдаёт заголовки `Access-Control-Allow-Origin`, откройте
приложение с прокси: `index.html?proxy=https://ваш-прокси` — тогда все
запросы пойдут на `<proxy>/journals/...` и т.д.

## 🛠️ Технологии

| Слой | Что используется |
|------|------------------|
| UI | Slint 1.x (рендер `renderer-femtovg`, WebGL) |
| Логика/сеть/крипта | Rust → WebAssembly |
| Сеть | браузерный `fetch` + `AbortController` (таймауты) |
| Async | `wasm-bindgen-futures` (однопоточно, `spawn_local`) |
| Крипта | Web Crypto (KEK) + `aes-gcm`/`hkdf`/`sha2` (данные) |
| Хранилище | localStorage (шифрованные записи) + IndexedDB (KEK) |

## 📦 Сборка из исходников

### Требования

- **Rust** (stable) + wasm-таргет:
  ```bash
  rustup target add wasm32-unknown-unknown
  ```
- **wasm-bindgen-cli** (версия должна совпадать с версией крейта
  `wasm-bindgen` в `rust/Cargo.lock`):
  ```bash
  cargo install wasm-bindgen-cli --version 0.2.125
  ```

### Сборка

**Windows (PowerShell):**
```powershell
.\build_web.ps1
```

**Linux / macOS:**
```bash
./build_web.sh
```

Или вручную:
```bash
cargo build --release --target wasm32-unknown-unknown
wasm-bindgen target/wasm32-unknown-unknown/release/burmalda57.wasm \
    --out-dir web/pkg --target web
```

### Запуск

`file://` не подходит — нужен любой статический HTTP-сервер:
```bash
cd web
python -m http.server 8080
```
Открой [http://localhost:8080](http://localhost:8080).

### Вход

Нажми «Войти» и вставь значение cookie `X1_SSO` (см. окно с подсказкой) —
дальше всё как в мобильном приложении, включая выбор ребёнка для
родительских аккаунтов. Есть и демо-режим без входа.
